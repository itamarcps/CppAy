# Local music samples

This folder intentionally contains no distributable music. Private development
samples and WAV references are ignored by Git and are not packaged.

The public suite uses newly authored synthetic inputs in `tests/fixtures`.
For optional Flexo02 golden checks, supply your own authorized `Flexo02.pt3`
and `Flexo02.wav` here, then enable `AYPLAYER_GOLDEN_TESTS` as described in
[testing](../docs/TESTING.md).
